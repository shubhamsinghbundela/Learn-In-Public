# Learn in Public Streak Tracker

A full-stack web application that allows users to publicly track what they're learning, maintain a daily learning streak, and share their progress using a unique public URL.

## Deployed URL

- **Frontend:** https://learn-in-public-teamshiksha.vercel.app
- **Backend API:** https://learn-in-public.onrender.com
